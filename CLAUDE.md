# OUTLIERS: Overclock — notes for Claude

- Hero: Null (Iris Calloway), violet is her signature colour. Surge = digital burst (pixel-tile ground scan, data wall, voxel cubes, screen glitch). Ultimate = Root Access (time freeze scan, reticle tags, everything hangs, then flung at once). Story bible in `docs/STORY.md` (v2: five rules, three layers of reality, Moth's-chair frame — new story content must obey the rules).

- Powers unlock through the chapter (`PROG.unlock`, `unlockPower`): lift + catch from the start (catch includes bullets: touch a bolt to freeze it, release = back to its shooter, flick = aim), Surge at the plaza relays, Rewrite at the tram cut (press-and-hold still: wall -> tear a liftable 'wallslab' + gap; street -> temporary cover wall; cordon gate -> flickers, 'RENEWED xN'; all edits heal via `EDITS`/`updateEdits`), Root Access during the lockdown.
- World = Chapter 1 "Uncounted", ~45-60 min, 10 zones in route order: Harrow Street -> Checkpoint Plaza (relays) -> Tram Cut -> Pier 9 Market -> Cold Storage (rescue) -> Gut Lane -> Rail Yard (lockdown + Lamplighter) -> Container Yard (informant chase) -> Pier 9 docks (Auditor retreats) -> Ferry Pier (Auditor rematch) -> Moth's door. Zones are rect lists anywhere in the world (`ZONES`, `rectOf`, level.js); gate i (`GATES`) opens when zone i clears. Rect options: openN/openW/openS (water edges), pitch (steeper camera in narrow E-W lanes). Steps/missions + dialogue + memory fragments in `src/chapter1.js`; mission code in main.js (relays, cages/civs, lockdown, chase, auditor1/2). Props per zone in `ZONE_PROPS` (props.js), loaded only for the current zone +-1. Lights go through an 8-light pool (`addSpot`), never raw PointLights.
- Enemies: counter, marksman, lobber, auditor, warden (riot shield blocks frontal hits; Surge/explosions/side hits knock it off -> liftable 'riotshield' prop), clerk drone (stamps props locked), lamplighter (searchlight drone boss), informant (chase). Drones use `def.drone` + `fly` hover force.
- Navigation (main.js `NAV`): rects of a zone that touch are linked, zones link only through openable gates; `navRoute` walks that graph so the objective arrow follows streets. Rects can carry a `name` (e.g. 'TRANSIT SHED') shown as the place label + toast. Minimap top-right (tap -> full map, pauses). Objectives: `setObjective(text, pos, label)`.
- Buildings south of an E-W lane occlude the top-down camera: keep them low or give the lane rect a `pitch`.
- Progression in `src/progress.js` (XP, levels, 8 tattoo skills x3 ranks, checkpoint) saved to localStorage; skill screen = "the arm". Plan: hub (Moth's parlor) + city map + one chapter per story-bible location.
- Owner plays on iPhone (portrait first) and uploads/deploys from his phone. Keep the playable build FLAT at the repo root: `index.html` + `pack1.js`..`pack3.js`. Push changes directly to `main`.
- Source lives in `dev/src` (three.js r187 + cannon-es, bundled by esbuild into one inline script). Build with `cd dev && npm install && node build.js`; repack assets with `python3 pack.py` only when `dev/assets_src` changes.
- Assets are loaded from base64 "packs" (`window.__AP`) because claude.ai artifacts refuse to serve .glb/.hdr; the loader falls back to loose files.
- Characters: Rocketbox (Bip01 biped bones), Auditor = Mixamo (mixamorig bones). Enemy visuals no longer have the old procedural `parts` object — use `e.char`, `e.bones`, `e.gear`.
- Every game system runs through `safe()` in the frame loop; errors show next to the fps counter (bottom-left) instead of freezing the game.
