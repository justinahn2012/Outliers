# OUTLIERS: Overclock — notes for Claude

- Hero: Null (Iris Calloway), violet is her signature colour. Surge = digital burst (pixel-tile ground scan, data wall, voxel cubes, screen glitch). Ultimate = Root Access (time freeze scan, reticle tags, everything hangs, then flung at once). Story bible in `docs/STORY.md` (v2: five rules, three layers of reality, Moth's-chair frame — new story content must obey the rules).

- Powers unlock through the chapter (`PROG.unlock`, `unlockPower`): lift + catch from the start (catch includes bullets: touch a bolt to freeze it, release = back to its shooter, flick = aim), Surge at the plaza relays, Rewrite at the tram cut (press-and-hold still: wall -> tear a liftable 'wallslab' + gap; street -> temporary cover wall; cordon gate -> flickers, 'RENEWED xN'; all edits heal via `EDITS`/`updateEdits`), Root Access during the lockdown.
- World = Chapter 1 "Uncounted", ~45-60 min, 10 zones in route order: Harrow Street -> Checkpoint Plaza (relays) -> Tram Cut -> Pier 9 Market -> Cold Storage (rescue) -> Gut Lane -> Rail Yard (lockdown + Lamplighter) -> Container Yard (informant chase) -> Pier 9 docks (Auditor retreats) -> Ferry Pier (Auditor rematch) -> Moth's door. Zones are rect lists anywhere in the world (`ZONES`, `rectOf`, level.js); gate i (`GATES`) opens when zone i clears. Rect options: openN/openW/openS (water edges), pitch (steeper camera in narrow E-W lanes). Steps/missions + dialogue + memory fragments in `src/chapter1.js`; mission code in main.js (relays, cages/civs, lockdown, chase, auditor1/2). Props per zone in `ZONE_PROPS` (props.js), loaded only for the current zone +-1. Lights go through an 8-light pool (`addSpot`), never raw PointLights.
- Enemies: counter, marksman, lobber, auditor, warden (riot shield blocks frontal hits; Surge/explosions/side hits knock it off -> liftable 'riotshield' prop), clerk drone (stamps props locked), lamplighter (searchlight drone boss), informant (chase). Drones use `def.drone` + `fly` hover force.
- Where-am-I (main.js `NAV`): rects can carry a `name` (e.g. 'TRANSIT SHED') shown as the place label + toast. Minimap top-right (tap -> full map, pauses). No route arrow or path lines: Justin wants location, not directions.
- Buildings south of an E-W lane occlude the top-down camera: keep them low or give the lane rect a `pitch`.
- Progression in `src/progress.js` (XP, levels, 8 tattoo skills x3 ranks, checkpoint) saved to localStorage; skill screen = "the arm". Plan: hub (Moth's parlor) + city map + one chapter per story-bible location.
- Owner plays on iPhone (portrait first) and uploads/deploys from his phone. Keep the playable build FLAT at the repo root: `index.html` + `pack1.js`..`pack3.js`. Push changes directly to `main`.
- Source lives in `dev/src` (three.js r187 + cannon-es, bundled by esbuild into one inline script). Build with `cd dev && npm install && node build.js`; repack assets with `python3 pack.py` only when `dev/assets_src` changes.
- Assets are loaded from base64 "packs" (`window.__AP`) because claude.ai artifacts refuse to serve .glb/.hdr; the loader falls back to loose files.
- Characters: Rocketbox (Bip01 biped bones), Auditor = Mixamo (mixamorig bones). Civilians/informant = 'civ_m' (Male_Adult_18, hoodie) and 'civ_f' (Female_Adult_14), built with FBX2glTF + gltf-transform in /home/claude/assets (civ_tex.py, civ_build.mjs). `addRim` (assets.js) gives Null a violet edge and the Census a faint amber one. Warden shield is strapped to the left forearm via `twoBoneIK` (hero.js); `__dbg.cam(px,py,pz,tx,ty,tz)` + `__dbg.freeze(true)` make a photo booth for close-ups. Enemy visuals no longer have the old procedural `parts` object — use `e.char`, `e.bones`, `e.gear`.
- Visual language: enemy ring colour + shape = type (counter red solid, marksman amber chevron, lobber green dashed/spinning, warden cyan double, informant white dots, auditor crimson dial, clerk diamond), dark backing disc; rings flare during windup/aim/throw. Hits: white pop (80 ms, 7% scale) then violet decay. Deaths are a pixel dissolve (`uDis` in `addRim`) with amber voxels ("counted out"). Hits: violet flash + `bendBone` flinch away from `e.hitDir`. Census idle = angry mocap; <40% HP they blend to injured walk/run (`hwalk`/`hrun`). Marksman rifle is shouldered via two-hand `twoBoneIK`; punches twist the spine. Null's forearm tattoo bands glow with power. Facades pick from dark brick / red brick / factory brick / painted plaster (seeded).
- Facades live in `src/facade.js` (`makeFacadeKit`): shopfronts (`kit.storefront`, themed interior-mapped rooms: noodles/mart/laundry/pawn/bar/pharmacy/repair, or a tagged shutter), upper windows (`kit.window` -> instanced interior mapping with a room atlas, curtains, silhouettes), set dressing (`kit.dress`: fire escapes on camera-facing faces, drainpipes, AC units). Every pane is breakable: `level.facade.hitSphere` (swept, from `updateGlass` for props/ragdolls), `hitSegment` (bolts crack, hero bolts shatter), `blast` (Surge, explosions); shards are one InstancedMesh pool.
- Story twist (docs/STORY.md "The final twist"): Iris is the one who wipes out the population; the game is replayed in an empty present from Moth's chair. Never state it before Act 3; seeds only.
- Art panel: brief + screenshots in `docs/art/` (BRIEF.md, shots/); artists' reports land there (art_director.md, environment.md, characters.md, lighting_vfx.md).
- Lighting (art panel phase 1): procedural night env (`buildEnvironment`, no HDRI lighting), hemi 0x3d5a66/0.22, moon 0.38, exposure 1.12, bloom threshold 1.05. Light pool = 6 PointLights ranked by contribution with hysteresis/fades; `addSpot` forces decay 2 (old intensities x1.7). Every spot gets a ground pool decal, shops spill (`kit.shops`), wet-street streaks (`L.updateGround`). Colour ownership: violet = Null only, amber (#ff9a1a) = Census only, sodium lamps pale #ffbf80, cold lights #d8f2ff. Rim (`addRim`) is edge-only: 4th arg is a threshold (0.72 Null, 0.8 Census). Cyberpunk layer lives in `src/cyber.js` (`makeCyber`, `G.cyber`): LED base strips snapped to wall bodies (skip openN/S/W water edges), Consensus floor plates (location only), roof holo-billboards (mandatory row on roofs just south of a lane), skewed cable spans between facades, ID tags + prop records (one instanced call; replaces enemy HP sprites), flying drones/spinners that fly the street corridors (long axis of the rect she is in, never through buildings; in fights too, less often) with height cues straight below: light pool + shadow, soft downwash ripples, a cone of lit rain from the hull (Justin: no collisions, just make it obvious they fly). Touching a flier pulls it down: `cyber.pluck` + `makeProp('skydrone'|'spinner')` (templates via `registerTemplate` in props.js), then a normal hold (`__dbg.grabFlier(i)`), write/heal FX (`cyber.writeBorder`/`healSweep`/`later`), ground lapse cells (Gut Lane, docks, ferry), static sea grid; batch 2: shop holo-awnings + light rugs (`facade.shops[].kind`), roof tech farms (not on lane-south roofs: they sit under the camera), cyan lamp collars (`level.lampPosts`), vending machines on facade `anchors`, Census scanner arches (NO RECORD tag via `C.tagHooks`) + camera domes with view cones, Tram Cut maglev beam, blade signs (Cantor script), relay count rings (`G.relays`). Cold Storage is AR-dark (no strips/plates/cables); strips stop 15 m from Moth's door. Camera follow uses the rect she's in before padded neighbours (junction clamp bug). Remaining from `docs/art/cyberpunk_addendum.md`: 12 cordon ledger, 16 screen windows, 19 steam, 20 crowd, typography. Earlier plan: (LED kerbs, AR floor projections, roof holo-billboards, ID tags, cable canopy, flying traffic, pixel decay) + phase 2 (zone floors, signs facing camera, roofs, landmarks).
- Held = written (`src/digitize.js`, `G.digit`): any prop that is held, Root-Access-tagged or in flight is rendered as a voxel model of light cubes (surface voxelised once per prop type and cached, colours sampled from its own textures, cells maxDim/9 clamped 0.12-0.18 m (Justin: 0.16-0.25 too coarse, 0.06-0.12 too fine to notice), cubes at 84% of the cell so the lattice reads, one InstancedMesh child per object), violet cube edges, data pulse, ripples rolling through (two slots), selection boxes with marquee ants, twinkling cubes, upward data streams, scan lines, blinking cells, shed cubes; voxel colours clamped to 0.6 so lamps don't blow out, ground anchor ring + blob. Grab = violet scan up (0.18 s); settle = amber re-render line (0.24 s) + cube burst. Mesh children are hidden while digital (lights stay on). `__dbg.grabProp(type)` grabs the nearest prop.
- Trails (`src/trails.js`, `G.trails`): one instanced draw of tapered streaks (Census bolts amber head->tail, her bolts violet, thrown props a violet ribbon) + street glow under bolts.
- Perf (`src/batch.js`): after the level is built, `staticBatch` folds static opaque meshes (scene children + Groups flagged `userData.static`) into one mesh per look x 48 m cell, colour baked into vertex colours and texture repeats into UVs; exclusions = `wet.hide`, fade objects, `level.noBatch`, ShaderMaterial/transparent/onBeforeCompile materials. `mergeGroupByMaterial` folds prop templates and cages to one draw per material. `__dbg.rstats()` = [calls, tris], `__dbg.drawProfile()` = calls by owner. Typical: 140-330 calls, 160-380k tris.
- Every game system runs through `safe()` in the frame loop; errors show next to the fps counter (bottom-left) instead of freezing the game.
